### 📊 Professional Coding Standards:
I prioritize **Idiomatic .NET code**, including:
- **Asynchronous Programming:** Full use of `async/await` and `Task` for scalable performance.
- **Dependency Injection:** Implementing loosely coupled architectures for better testability.
- **DTO Pattern:** Decoupling database entities from the public API layer for security and integrity.
- **AAA Testing Pattern:** Writing robust unit tests using the Arrange-Act-Assert methodology.
